# Impeccable Style — Visual Design Craft

## 1. Visual Precision & Elevation
- **1px Crisp Borders**: Use subtle translucent borders (`border: 1px solid rgba(255, 255, 255, 0.08)`) with inner highlights rather than thick solid borders.
- **Layered Ambient Shadows**: Create depth through multi-layer shadows rather than flat dark drop shadows:
  ```css
  box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.3), 0 20px 40px -15px rgba(0, 0, 0, 0.6);
  ```
- **Optical Alignment**: Text labels and icons must be vertically centered with optical compensation.

## 2. Spatial Rhythm & Grid Consistency
- Use a 4px/8px spatial scale (`4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`, `64px`).
- Input fields must have consistent internal padding (`0.75rem 1rem`), min-height (44px for WCAG touch targets), and `box-sizing: border-box`.

## 3. Micro-Copy & Healthcare Polish
- Clinical terminology must feel authentic and localized (e.g. "Board-Registered Clinicians", "DISHA Compliant", "INR ₹ Pricing", "PIN Code").
- Never use generic placeholder text or template filler.
